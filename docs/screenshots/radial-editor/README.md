These screenshots render the actual Jetpack Compose editor toolbar and notebook paper with Android 35 and native Skia through Robolectric. They are generated by `EditorToolbarTest`, using the in-activity layout path so the toolbar and document can be captured together; separate tests exercise the real floating Popup windows and screen-coordinate dragging.

- `tablet-light.png`: 1200 × 800 dp, light theme, pen selected.
- `tablet-dark.png`: 800 × 1100 dp, dark theme and dark paper.
- `phone-large-text.png`: 412 × 915 dp, light theme, 150% text scaling.
- `highlighter-light.png`: 800 × 800 dp, highlighter selected with its own width and color presets.

Regenerate with `./gradlew :app:testDebugUnitTest --tests 'app.noti.ui.editor.EditorToolbarTest'`. The fresh renders are written to `app/build/reports/editor-ui/`. These are host-rendered Android UI captures, not physical tablet captures; native ink rendering and Focus Pen hardware require a device.
